# Exporting Graphs — Voiceover Script

**Video:** [`../../recordings/exporting-graphs.mp4`](../../recordings/exporting-graphs.mp4)  
**Runtime:** ~46.4s  
**Delivery:** warm, direct, ~150 wpm. Pause after each question and let the evidence land.

## Intro (0:00–0:06)

> rgctl is an open-source, MIT-licensed code knowledge graph built in Rust for AI coding agents.
>
> In this walkthrough, a coding agent chooses the right graph export for Gephi, Mermaid, Obsidian, and an archival JSON snapshot.

## Walkthrough

### Beat 1 — Pick the destination

> GraphML goes to Gephi, Mermaid goes into a design doc, Obsidian gets a browsable vault, and JSON becomes the archive. The agent chooses the format from the destination, not from habit.

### Beat 2 — Scope the export

> Each export is filtered by a query. The viewer sees the graph being shaped for its audience instead of dumping every node into one unreadable file.

### Beat 3 — Keep the evidence

> The point of export is not a picture. It is a durable artifact other tools and people can inspect after the agent is gone.

## On screen

- “Export the call graph so I can open it in Gephi. Which format should you use?”
- “Make a Mermaid diagram of the checkout call graph for a design doc.”
- “I want to browse this codebase as an Obsidian vault, one note per section.”
- “Save a JSON graph snapshot for later comparison.”
