**Delivery:** warm, direct, ~150 wpm. Pause after each question and let the evidence land.

## Intro (0:00–0:06)

> rgctl is an open-source, MIT-licensed code knowledge graph built in Rust for AI coding agents.
>
> In this walkthrough, a coding agent uses the dashboard and semantic API to explore the graph without losing the structural evidence.

## Walkthrough

### Beat 1 — Explore visually

> The agent starts the dashboard and points out the views worth opening first. The dashboard is for exploration; the structural CLI verbs remain the source of answers for agents.

### Beat 2 — Share and query

> A teammate can inspect the graph without cloning the repository. The semantic API lets an agent ask a natural-language question and get a structured answer.

### Beat 3 — Keep it fresh

> When the dashboard looks stale, the agent checks index freshness and the watcher instead of trusting the screen. The UI is only as good as the snapshot behind it.

## On screen

- “Start the dashboard for this repo and tell me what I should look at first.”
- “How can a teammate explore this graph without cloning the repo?”
- “Use the semantic API to find checkout-related functions and show the request and response.”
- “The dashboard looks stale after my edits. What should we do?”
